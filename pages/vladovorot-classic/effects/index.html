Ефекти Владовороту

    Натисни на комірку, щоб вибрати категорію з колеса. Стан зберігається в браузері.

    Налаштування OBS

    1. Додай 2 джерела «Браузер» (не копіюванням). Ідея в тому, що перше джерело показується на сцені, а друге приховане, бо в ньому редагуються комірки через опцію «Взаємодіяти».
    2. Встав посилання на цю сторінку.
    3. Ширина: 504 (для 7 комірок у рядку), висота: 500. Ширину можна зменшувати кратно 72 пікселям.
    4. CSS для видимого джерела: 
      body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; }
.obs-hide { display: none; }
    5. Увімкни опцію « Оновити браузер, коли сцена стає активною».
    6. Після редагування комірок потрібно перемкнути видимість першого джерела, щоб підтягнути зроблені зміни.
